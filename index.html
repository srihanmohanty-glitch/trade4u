Or install via pip:

pip install git+https://github.com/srihanmohanty-glitch/trade4u.git

Or clone and install:

git clone https://github.com/srihanmohanty-glitch/trade4u.git cd trade4u && pip install -e .

🤖 Enable AI Features

For AI-powered analysis, install Ollama:

macOS:

brew install ollama && ollama serve

Windows:

Download from https://ollama.com

Then pull a model:

ollama pull llama3.2
